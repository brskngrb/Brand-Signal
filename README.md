# Brand Signal

Brand Signal（原 Bakery Clearly）是 Windows 本機品牌內容分析工作台，以鴻鼎菓子的官網、商品圖與彌月禮盒情境為範例。它把蒐集、商品建檔、內容改善與外部 AI 觀測放在同一個工作區。

## 在 Windows 啟動

1. 下載或 clone 此儲存庫。
2. 雙擊 `start-local.cmd`。首次啟動會安裝缺少的依賴，請保持網路連線。
3. 開啟 [本機工作區](http://localhost:59935/)。
4. 在「設定 → 模型與 API」選擇供應商與模型，再測試連線。

使用 `start-with-logs.bat` 可查看啟動及後台紀錄。`stop-ollama-and-node.bat` 會關閉電腦上執行中的 Ollama 和 Node 程序，使用前請先結束其他相關工作。

## 選擇模型

| 選項 | 設定方式 |
| --- | --- |
| Ollama | 選擇本機已下載的模型。圖片辨識需使用支援圖像輸入的模型。 |
| OpenAI | 在設定頁輸入金鑰，或在本機 `.env` 設定 `OPENAI_API_KEY`。 |
| Gemini | 在設定頁輸入金鑰，或在本機 `.env` 設定 `GEMINI_API_KEY`。 |
| Tavily | 在本機 `.env` 設定 `TAVILY_API_KEY`，供品牌觀測的搜尋批次使用。 |

伺服器端設定從 `.env.example` 複製一份為 `.env`，填入自己的金鑰後重啟。雲端模型與搜尋工具依帳戶方案計費。

## 工作流程

1. **收集與分析**：在首頁執行「一鍵分析網站」，依商品詳情頁收集文字與圖片，再建立商品資料。若已有資料，可直接用「分析已保存資料」。
2. **核對商品與改善建議**：展開商品即可查看按分類整理的欄位，點商品名稱可開啟官網。靜態擷取缺少價格或規格時，流程可用所選模型補讀尚未辨識的商品圖片。仍缺證據的欄位需核對實際頁面。首頁最多呈現三項有證據的優先改善。
3. **內容與助理**：貼入 HTML 或純文字執行內容健檢，或使用已設定的模型協助整理內容與修改方向。
4. **品牌觀測**：保留題目、回答和引用。品牌提及、推薦與官網引用依各項已查核的有效回答計算。外部網頁問答、API 採樣及 Tavily 搜尋各有不同用途。

## 資料與開發

本機資料庫、圖片與分析紀錄存放在 `data/`，執行環境和模型存放在 `.runtime/`。部分介面偏好保存在瀏覽器。這些本機資料與 `.env` 由 Git 忽略，clone 後請各自設定並蒐集資料。

使用 Node.js 24 以上，在專案根目錄執行：

```powershell
npm ci
npm test
npm run build
npm run validate
```

建置輸出位於 `dist/`。
